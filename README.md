Project Description

This project builds upon my Week 1 semantic HTML portfolio by introducing CSS styling, layout techniques and responsive web design.

The goal is to create a consistent, accessible and responsive portfolio that works across different screen sizes.

Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Google Fonts

Features

- Shared CSS stylesheet across portfolio pages
- CSS reset and consistent typography
- Reusable CSS custom properties for colours, fonts and spacing
- Box-model practice and card components
- Flexbox navigation and layouts
- CSS Grid project gallery
- Responsive layouts for mobile, tablet and desktop
- Hover effects and keyboard focus indicators
- Styled contact form

Project Structure

- "index.html" — Home page
- "about.html" — About page
- "projects.html" — Projects page
- "contact.html" — Contact page
- "box-model-practice.html" — Box-model exercises
- "styles.css" — Shared stylesheet

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser, or use the Live Server extension.
4. Navigate through the portfolio pages.

Lessons Learned

- How the CSS box model determines the size and spacing of elements.
- How CSS custom properties make styles easier to maintain.
- How Flexbox handles alignment and distribution of elements.
- How CSS Grid creates structured page layouts.
- How responsive media queries adapt layouts to different screen sizes.
- Why semantic HTML, keyboard accessibility and visible focus states matter.

Challenges Faced

- Resolving Git merge conflicts while setting up the weekly repository.
- Maintaining consistent styling across multiple HTML pages.
- Adjusting layouts to prevent overflow on smaller screens.
- Understanding how different CSS layout techniques interact.
