# Week 4: JavaScript Fundamentals

## Overview
This project demonstrates JavaScript fundamentals, data manipulation, and interactive webpage features.

## Features

### Calculator
- Addition, subtraction, multiplication, and division
- Remainder and exponentiation
- Division-by-zero handling
- Input validation

### Student Grade Tracker
- Display student names, scores, and grades
- Add students with score validation
- Calculate the class average
- Identify the highest-scoring student
- Update the displayed student list and statistics

## Technologies
- HTML
- JavaScript

## How to Run
1. Open `index.html` using VS Code Live Server.
2. Use the calculator to perform calculations.
3. Use the student tracker to view and add student records.

## Learning Outcomes
- Variables, data types, operators, and functions
- Conditional statements and loops
- Arrays, objects, and array methods
- JSON parsing and stringification
- DOM manipulation and event listeners
- Input validation and error handling
